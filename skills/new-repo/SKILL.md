# new-repo

Initialize a repository to the standard from this platform's templates with `bin/new-repo`: the instruction and policy files, pull request template, code owners, dependency updates, check and release workflows, the hygiene check, the version script, the decision-record template, the empty specification skeleton (`docs/spec/SDD.md`, `TDD.md`) and the amendment ledger, on `main` and `develop`, with the branch rulesets applied when a GitHub repository is named. Verifies the result with the repository's own check before reporting.

This is the contract. The procedure is filled in when the skill is first exercised, and it never widens beyond this paragraph without a decision.
