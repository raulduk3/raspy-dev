# spec-lint

Check a specification tree for the repository standard: every subsection carries its lock marker, every status marker cites an issue by number, every issue cited exists and is open or closed for the stated reason, no section names a person, agent, model, session or process history, and every `Describes release:` header matches the current tag or candidate. Reports findings with file and line; edits nothing.

This is the contract. The procedure is filled in when the skill is first exercised, and it never widens beyond this paragraph without a decision.
