# NNNN. Title in the imperative, under 60 characters

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD
- Issue: #N
- Spec: the SDD and TDD items the decision changes
- Pull requests: #N (or "pending")

## Context

The situation that forced a decision, in two or three sentences. What was observed, what the contracts said, what the code did.

## Decision

What was decided, stated as a rule the code and contracts now follow. Exact names where they matter.

## Consequences

What changes because of it: behavior, contracts, tests, operations. What becomes impossible. What is deliberately left open, with its issue.
